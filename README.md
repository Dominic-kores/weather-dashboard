# weather-dashboard

A responsive weather dashboard built with HTML, CSS,
and JavaScript using the OpenWeatherMap API.

## Project Overview

This application allows users to search for weather
conditions in cities around the world.

It displays current weather information, upcoming
forecast data, and recent search history.

## Features

- Search weather by city name
- Current temperature in Celsius
- Weather condition descriptions and icons
- Humidity and wind speed
- Feels-like temperature
- Upcoming five-day forecast
- Search history with localStorage
- Loading and error states
- Responsive design

## Getting Started

1. Clone the repository.

   git clone https://github.com/Dominic-kores/weather-dashboard

2. Open the folder in VS Code.

3. Obtain an API key from OpenWeatherMap.

4. Replace YOUR_API_KEY_HERE in script.js.

5. Start a local HTTP server.

## Live Pages
https://dominic-kores.github.io/weather-dashboard/

6. Visit http://localhost:5500

## API Endpoints

Current weather:
https://api.openweathermap.org/data/2.5/weather

Forecast:
https://api.openweathermap.org/data/2.5/forecast
